# @fudgo/api-contracts

Canonical OpenAPI schema for the Fudgo platform API. This package is the
contract between the FastAPI backend (`apps/api/`) and the future Flutter
mobile (`apps/mobile/`) and web (`apps/web/`) clients.

## What lives here

- `openapi.json` — checked-in OpenAPI 3.1 schema generated by
  `tools/scripts/generate_openapi.py`. **This file is the source of truth**;
  web and mobile clients MUST consume it (or generated types) rather than
  re-deriving it from the live server.

- `python/` — generated Pydantic models mirroring the schema. Reserved for a
  future phase that needs Python-side validation of mobile/web payloads.

- `typescript/` — generated TypeScript types. Gitignored; the contracts CI
  workflow regenerates them on every change to `apps/api/` so they are never
  stale in a checked-out branch.

## How to update the schema

1. Edit the FastAPI code under `apps/api/`.
2. Run `just contracts-generate` from the monorepo root.
3. Review the diff: `git diff packages/api-contracts/openapi.json`.
4. Commit the regenerated `openapi.json` alongside your code change.

The `contracts-ci` workflow in `.github/workflows/contracts-ci.yml` runs the
generator on every PR that touches `apps/api/` or `tools/scripts/` and fails
the build if the checked-in `openapi.json` is out of date.
